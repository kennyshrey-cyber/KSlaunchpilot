Case study

Felon Friendly Jobs Now

Industry
Jobs & services directory
Project
Multi-category directory platform
Scope
Strategy, UX, design, development

The Challenge

Bring job listings and service providers across several categories into one searchable platform that is easy to browse and easy to manage.

The Approach

We mapped each type of user and listing before designing anything, then defined the categories, fields and journeys the platform needed to support.

Design

A consistent listing layout across categories, with search and filters that stay simple as the directory grows.

Development

Dynamic listings, search and filtering, with CMS and backend functionality for adding and managing entries.

Outcome

A launched directory platform, structured so new categories can be added without a redesign.
